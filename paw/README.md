# Paw

Маленький мультяшный друг для рабочего стола. Первый рабочий прототип на Electron: собачка Бадди, котик Моти и крокодильчик Киви.

## Что уже работает

- Отдельное прозрачное окно поверх других окон, прогулки в пределах рабочего стола и перетаскивание мышкой. Пустые поля окна пропускают обычные нажатия.
- Питомец отдыхает, гуляет, играет и охотится за бабочкой. Нажатие — погладить; правая кнопка — меню.
- Три скина; шапочки, очки, шарфики, косточка и мячик. Можно сочетать несколько аксессуаров. Скин, одежда, звук и прогулки сохраняются локально.
- Тихие синтезированные мультяшные звуки при общении. Их можно выключить.
- Кормление: перетащить обычный файл на питомца или выбрать через «Покормить». **Файл сразу отправляется в системную корзину, без подтверждения.** Можно восстановить через корзину. Безвозвратное удаление не используется. Папки и символические ссылки не принимаются; максимум 20 файлов за раз.
- Wi-Fi: команды включения/выключения на macOS и Windows с проверкой состояния. Система может требовать дополнительные права; приложение самостоятельно их не повышает. Ethernet не отключается.
- Bluetooth: Windows WinRT Radio API с проверкой результата; на Mac открываются системные настройки Bluetooth.
- Значок в строке меню/системном трее возвращает питомца и открывает гардероб.

## Запуск на своём компьютере

Целевые системы: macOS 12+ (Intel x64 и Apple Silicon arm64), Windows 10/11 x64. Для разработки рекомендуется Node.js 24 LTS и npm.

Открой терминал в папке `paw`:

```sh
npm ci
npm start
```

Если npm не загрузил бинарник Electron автоматически:

```sh
node node_modules/electron/install.js
```

Появится окно домика и маленький питомец. Домик можно закрыть: питомец останется на экране. В его меню есть команды сна, игры, звука, Wi-Fi, Bluetooth, гардероба и выхода.

## Проверки

```sh
npm test
```

20 тестов: восстановление настроек и одежды, границы нескольких мониторов, выбор только физических Wi-Fi адаптеров, проверки ошибок прав и состояния Bluetooth/Wi-Fi. Тесты системных команд используют имитацию ОС; они не заменяют проверку на Mac/Windows.

Проверка интерфейса в Chromium:

```sh
npm run test:ui
```

Требуется Chromium (`/usr/bin/chromium` по умолчанию; можно задать `PAW_CHROMIUM`). Проверяются смена питомца, сон, четыре аксессуара одновременно, сохранение, звук и прогулки, адаптивный интерфейс. Скриншоты пишутся в `test-results/`.

Проверка настольного приложения на подготовленной Linux-машине с X-дисплеем:

```sh
DISPLAY=:99 npm run test:desktop
```

В этой облачной среде тест может сам поднять и остановить отдельный виртуальный дисплей:

```sh
bash scripts/cloud-desktop-test.sh
```

Проверяется реальное прозрачное окно, синхронизация питомца и гардероба, охота, сохранение после перезапуска и настоящее кормление **специально созданным тестовым файлом** без подтверждения. Тест оставляет его восстанавливаемым в отдельной тестовой корзине `.runtime/paw-integration-*/data/Trash/`. В этой облачной среде только тестовый процесс запускается с `--no-sandbox`, поскольку ядро не предоставляет sandbox Chromium. Обычный запуск и настройки сборки этого флага не содержат.

## Сборка установщиков

На Mac:

```sh
npm run dist:mac
```

На Windows:

```sh
npm run dist:win
```

Результаты появятся в `release/`. Команда Mac запрашивает отдельные x64/arm64 DMG, Windows — x64 NSIS. Эти сборки в облачной Linux-среде **не выполнялись**. Для публичного распространения нужны подпись/нотаризация Apple и подпись Windows. Учётные данные в проект не включены.

## Границы прототипа

Логика, интерфейс, запуск Electron и системная корзина проверены в Linux. Работа поверх окон, несколько мониторов и оборудование Wi-Fi/Bluetooth требуют проверки на целевых Mac и Windows. На macOS встроенного надёжного универсального переключателя Bluetooth здесь нет — используется переход в настройки. Исходники не содержат облачного ИИ, распознавания речи, автозапуска и автоматических обновлений. Питомцы нарисованы оригинальными SVG; звуки синтезируются, записей животных пока нет.

Проект добавлен новой папкой в репозиторий; исходные ZIP-архивы не изменены.
