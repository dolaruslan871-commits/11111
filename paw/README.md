# Paw 0.7.0

Обновление приложения Paw 0.6.3 из предоставленного app.asar. Автор: Руслан Доля / Ruslan Dolia.

## Установка

Полностью выйдите из предыдущего Paw через значок в трее или пункт «Выйти из Paw».

- Windows 10/11 x64: откройте `Paw-0.7.0-windows-x64-Setup.exe`. Установка для текущего пользователя, ярлыки на рабочем столе и в меню «Пуск». Удаление — через «Установленные приложения». Данные питомца при удалении сохраняются.
- Mac с M1/M2/M3/M4 и более новыми Apple Silicon: распакуйте `Paw-0.7.0-mac-arm64.zip` и перенесите `Paw.app` в «Программы».
- Mac с процессором Intel: используйте `Paw-0.7.0-mac-x64.zip`, также перенесите приложение в «Программы».

Сборки без цифровой подписи и нотарификации. macOS и Windows могут запросить подтверждение запуска. Если macOS блокирует приложение, используйте штатные настройки «Конфиденциальность и безопасность» для разрешения запуска доверенного приложения. Эти сборки не проходили запуск непосредственно на Windows или macOS.

Настройки и прогресс используют прежнее имя `paw-desktop-pet` и стандартное хранилище Electron. При замене версии они сохраняются. Резервная копия папки данных перед обновлением позволит откатиться на предыдущую версию.

## Что изменилось

- Paw Guide: пять шагов с кроликом, подсветкой настоящих элементов управления, прогрессом, возвратом, пропуском и повторным запуском через настройки. Русский, украинский и английский текст. Завершение и пропуск сохраняются. Награда — бесплатная «Звёздочка дружбы»; повторное обучение не расходует валюту.
- Смена питомцев: старый уходит, новый приходит; быстрый выбор меняет входящего питомца на последнего выбранного. При системном ограничении анимации применяется мгновенная смена.
- Чёрная, «Полночь» и «Тёмная слива» добавлены к существующим темам. Структура окна, разделы, карточки и привычные кнопки сохранены.
- Настройки рабочего стола: горячая клавиша показа/скрытия, выбор экрана, сброс позиции, прозрачность питомца, пропуск кликов, привязка к краям, сворачивание в значок. Двойной щелчок по значку разворачивает питомца.
- Пауза прогулок в меню правой кнопки мыши и быстрый переход в гардероб. В меню остаются погода, Bluetooth, звук, таймер, заметки и приложения.
- Парашют включён: отпущенный в воздухе питомец спускается вниз. Выключен: остаётся в месте, куда его перенесли. Опция привязки к краям действует при свободной установке после отпускания мыши.
- Экономия энергии: до 15 FPS в покое, обычный бюджет при активных действиях; скрытые сцены не перерисовываются. Максимальный FPS зависит от выбранного качества и устройства.
- Умное «Не мешать» скрывает питомца при обнаружении полноэкранного приложения и возвращает после выхода. Использует доступное в ОС определение активного окна на Windows/macOS; некоторые защищённые игры и приложения могут быть недоступны наблюдателю.
- Тихие часы дополнительно подавляют уведомления. Настройки частоты прогулок, внимания и характера остаются в разделе «Характер». Автозапуск — через настройки Paw и штатные возможности Windows/macOS.
- Домик перетаскивается мышкой и запоминает позицию. Переключатель видимости перенесён к строительству.
- Более подробная шерсть в High/Ultra, изменённые пропорции кошек и собак. Варианты кошек: полосатый, сиамский, британский; собак: ретривер, корги, далматин. Хаски остаётся отдельным питомцем. Порода выбирается в настройках для текущей кошки или собаки.
- Дополнительные строчки на одежде. Исправлена опора при сне, перекатах и еде. Молоток убран; крошки больше не вылетают изо рта. Сердечки подняты дальше от головы. Во время еды питомец наклоняется к корму.
- Левая кнопка: ухо — почёсывание, нос — короткая реакция, голова — поглаживание, три быстрых касания живота — один переворот. Перетаскивание отделено от касаний.
- Ожидание поклёвки сокращено на 50%; скорость вываживания удвоена. Окно реакции на поклёвку сохранено.
- Английская подпись создателя: Ruslan Dolia.
- Проверка обновлений читает последний публичный GitHub Release в `dolaruslan872-alt/354345`. Автоматическая проверка при запуске отключается в настройках. Установка обновления автоматически не выполняется.
- Кнопка удаления открывает системный список приложений Windows; на Mac показывает Paw.app в Finder для штатного удаления. Данные питомца сама кнопка не удаляет.
- Исправление ошибки `advanceTransport`: некорректные координаты не передаются в native API Electron. Добавлено восстановление потерянного WebGL-контекста.

## Проверки и ограничения

Проверены: синтаксис модулей; перенос прежних настроек; проверка координат, в том числе отрицательных на втором мониторе; модель спуска; жесты; определение полноэкранных границ; версия обновлений; ожидание рыбалки. В Chromium пройдены завершение, пропуск, повтор обучения, сохранение после перезагрузки и смена темы. Визуально проверены изменённые позы. Искусственная потеря WebGL-контекста завершилась восстановлением 3D.

Paw запущен в Electron 39.2.7 на Linux с виртуальным экраном. Проверены реальный IPC, язык и обучение, переключение прогулок в меню, перенос без парашюта, сброс позиции, награда, смена питомца, порода и сворачивание. Этот запуск не заменяет проверку Windows/macOS: автозапуск, системные Bluetooth/звук, полноэкранные игры, разные мониторы и Gatekeeper/SmartScreen требуют проверки на целевых компьютерах. Все анимации всех девяти питомцев во всех комплектах одежды вручную не проверялись.

## Исходники и сборка

Требуется Node.js 22+ и npm.

```sh
npm install
npm test
npm start
```

Windows: `npm run build:win` на Windows. macOS: `npm run build:mac` на Mac. Для подписанного распространения потребуются ваши сертификаты и параметры подписи/нотарификации. Зависимости разработки не включены в app.asar; runtime-модули уже находятся в `src/vendor`.

`app.asar` — общий код приложения для всех трёх сборок. Для ручной замены архив находится в `resources/app.asar` на Windows и `Paw.app/Contents/Resources/app.asar` на Mac. Замена внутри подписанного Mac-приложения нарушит его подпись; для обычной установки используйте готовый архив приложения.
